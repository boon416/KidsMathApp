# KidsMathApp 👶➕➖

A fun and interactive Android app designed to help kids learn basic math skills like comparing, ordering, and composing numbers. Built as an individual project using Java and Android Studio.

---

## ✨ Features

- 🧮 Compare two numbers (greater than, less than, equal)
- 🔢 Order a list of numbers from smallest to largest
- 🧠 Compose numbers from parts (e.g., 3 + 4 = 7)
- 🔊 Visual and audio feedback for correct/wrong answers
- 🎨 Kid-friendly UI with large buttons and colorful layout

---

## 📱 How to Use

1. Open the app and choose a game mode: Compare, Order, or Compose
2. Select difficulty level: 1-digit, 2-digit, or 3-digit numbers
3. Follow the on-screen instructions and receive instant feedback
4. Reset or try again anytime

---

## 🛠 Built With

- Java (Android)
- Android Studio
- XML Layouts
- Toast / Image Feedback
- SharedPreferences (if applicable)
